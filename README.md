# canvas_tweaks
Userscripts for making canvas more helpful. I recommend following James Jones' instructions for installing Tampermonkey and using userscripts to improve your experience with canvas: https://github.com/jamesjonesmath/canvancement/blob/master/USERSCRIPTS.md

## canvas_course_color
If you're working on two similar courses, or copying material back and forth, it's easy to get confused. Use this script to change the background color of one course site so you will always know which one you are looking at.
